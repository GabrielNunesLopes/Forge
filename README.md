# Pixel Forge Games

Loja virtual fictícia de hardware e periféricos gamer, feita como projeto acadêmico de Linguagem de Marcação / Desenvolvimento Web Frontend. O visual segue o padrão de grandes lojas brasileiras de tecnologia.

## Páginas

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Vitrine: carrossel de banners, categorias, Oferta Relâmpago (com produto esgotado) e mais procurados |
| `produto.html` | Detalhes do produto: galeria com miniaturas, preço, opções e ficha técnica em tabela |
| `carrinho.html` | Carrinho em tabela semântica e resumo do pedido com cupom |
| `cadastro.html` | Cadastro e checkout: dados pessoais, endereço e forma de pagamento |

## Como abrir

Abra o `index.html` no navegador, ou use a extensão Live Server do VS Code. As fontes vêm do Google Fonts; o resto funciona offline.

## Tecnologias

HTML5 e CSS3. O `script.js` cuida apenas do carrossel, das contas do carrinho e da confirmação do cadastro.

Produtos, preços e promoções são demonstrativos: nenhuma compra é realizada.
